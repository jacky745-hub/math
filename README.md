# 國中數學逐步鷹架解題系統（MVP）

這是一個可落地的最小可行版本（MVP），目標是做出：

- **逐步拆解**：提示分層（L0–L4），學生自己決定要看到多少提示
- **有溫度、低雜訊**：每次只給 1–2 個最關鍵錯因，避免資訊轟炸
- **符合鷹架與降低認知負荷**：先釐清任務 → 再選策略 → 再做微步驟 → 再回代檢查
- **引發後設認知**：每一層提示都有「反思提問」
- **後台可下載錯誤/迷思概念資料**：匯出 `errors.csv`、`submissions.csv`
- **支援上傳圖片或 PDF**：單題或整份作業皆可（MVP 對圖片不做 OCR；PDF 會做文字擷取）

> 注意：目前的「對錯判斷」與「錯因偵測」是 MVP 的規則式/符號運算版本，已預留後續接入更強分析（例如 LLM、OCR、題型分類器）的擴充點。

## 網頁部署方式（建議：Docker）

你要的是「不是本機執行、而是網頁版本 + 必須有資料庫」：此專案已提供 Docker 版，會在伺服器上跑成網站，並用 **SQLite 資料庫檔 + Volume** 做持久化（等同有 DB）。

在伺服器上（或任何有 Docker 的環境）：

```bash
docker compose up --build
```

然後用瀏覽器開 `http://<server-ip>:8080`

> 資料會存在 `./data/`（含 `mathcoach.sqlite3` 與上傳檔），重啟容器不會消失。

## （仍可選）本機執行

在專案根目錄：

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

啟動後：

- **學生**：填題目文字（必填），可上傳圖片/PDF，送出後會看到逐步提示
- **教師後台**：可直接看到最近提交清單，並下載 CSV

## 管理密碼（可選）

若要啟用管理密碼，設定環境變數：

```bash
export MATHCOACH_ADMIN_PASSWORD='your-password'
```

## 匯出資料格式

- `errors.csv`：一筆錯因/迷思概念一列（含提交資訊、最高提示層級、提示事件數）
- `submissions.csv`：提交清單（含正確與否、簡短回饋、上傳檔資訊）

## 目前限制（MVP）

- 圖片/手寫 OCR：已加入 Tesseract（實務上仍可能因字跡/光線而需學生校正）
- 對錯判斷以「可解析的方程式 + 有填最後答案」為主
- 錯因偵測：加入「逐行等價檢查」，可定位第一個偏掉的步驟；並先涵蓋移項/分配律/粗心等常見類別（可持續擴充）

## 下一步可擴充

- **圖片 OCR**：從手寫內容擷取步驟文字，提升錯因定位能力
- **題型分類**：方程式/比例/幾何/函數等，生成更貼題的鷹架路徑
- **步驟一致性檢查**：逐行驗證等量變形，精準指出「從哪一步開始錯」
- **班級/作業維度的迷思概念儀表板**：提供教學回饋與補救教學建議
