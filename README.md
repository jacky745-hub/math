# 小安 Xiao-An — 課堂 AI 助教

會聽、會說、會看、會動手的課堂 AI 助教網頁版。打開瀏覽器就能用，不需要安裝。

程式在 [`app/`](app/)，外觀依照「小安 Xiao-An」設計系統（色彩、字體、元件）。

## 怎麼開啟

1. 用 Chrome 或 Edge 開啟 `app/index.html`。
   建議放在網站上（例如 GitHub Pages：repo 的 Settings → Pages → 從 `main` 分支部署），這樣學生手機才連得到作答頁。
   在自己電腦上試用可以執行：

   ```bash
   cd app && python3 -m http.server 8000
   ```

   然後開啟 http://localhost:8000
2. 右側和小安對話：直接打字，或按「說話」／空白鍵用說的。說「你會什麼」可以看全部指令。

## 功能對照（skills.md）

| 技能 | 在哪裡 | 說明 |
| --- | --- | --- |
| 1. QR Code 派題、統計、文字雲、迷思分析 | 課堂互動 | 單選／多選／觀念思考題；學生掃 QR 作答；即時答對率、各選項比例、選錯最多的迷思；開放題自動斷詞做文字雲；可複製 R 程式碼重現統計、下載 CSV。 |
| 2. 黑板推導、函數繪圖、動態類題 | 黑板推導、函數繪圖 | 自由落體 H = ½gt²、二次函數配方、自訂推導，一步一步寫出並唸出；類題自動出題並驗算；拋物線標出頂點、焦點、準線、對稱軸。 |
| 3. 3D/2D 視覺與浮空字卡 | 視覺投影 | 動脈血管三層剖面（含血球流動）、正方體馬克杯；字卡逐一浮現；連上語言模型後可畫任意主題示意圖（SVG，會移除所有程式碼）。 |
| 4. Word 解題與寫回 | 文件共編 | 開啟 .docx 找出題目，寫入詳細解題與自我檢查，再加類題，另存新檔下載（不覆蓋原檔）。 |
| 5. 系統與應用程式操控 | 工具與操控 | 簡報開啟／全螢幕／放大縮小、Google 地圖路線、Google 日曆、寄信、Spotify、GeoGebra 等網站。 |
| 6. 主動協助、習慣記憶 | 全部 | 全班作答完主動問要不要統計；久未操作時提議出類題或解題；說「記住…」「我喜歡…」就會記下並套用。 |
| 安全與隱私 | 設定與記憶 | 寄信、存檔、開網站前都要老師確認；送出前自動遮蔽身分證字號、密碼、卡號；學生作答不含姓名。 |

## 需要語言模型的功能

不連語言模型也能使用：派題與統計、迷思分析（依老師設定的迷思說明）、文字雲、黑板推導、類題、函數繪圖、內建示意圖、公式可解的 Word 題目、語音指令、所有工具。

到「設定與記憶」填入 Claude API 金鑰後，另外可以：自由對話、深入分析迷思、解任意題目、依任意題目出類題、畫新的示意圖。金鑰只存在該瀏覽器，直接送到 Anthropic。

## 學生用手機作答

- 預設只接受「同一台電腦的其他分頁」作答，適合預演；也可以按「模擬全班作答」。
- 到「設定與記憶」開啟「跨裝置作答」，答案會經由公開中繼服務 ntfy.sh 傳回老師端（只傳隨機代碼與選項）。
  並在「學生作答頁網址」填入網站網址（例如 GitHub Pages 的網址）。

## 瀏覽器版的限制

- 語音輸入需要 Chrome 或 Edge；朗讀使用系統內建的中文語音。
- 地圖、日曆、郵件、Spotify 是在新分頁開啟，由老師完成最後一步；直接控制 Mac 本機程式需要另做本機版。
- 統計在瀏覽器內計算，並提供對應的 R 程式碼，沒有在網頁中執行 R。
- 台語語音模型尚未加入。
