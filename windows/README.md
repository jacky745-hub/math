# 小安 Windows 本機版

在 Windows 電腦上執行小安，就能直接操作這台電腦：

| 功能 | 說明 |
| --- | --- |
| PowerPoint | 開啟簡報、開始放映、上一頁／下一頁／跳到第 N 頁、結束放映。可以用說的（「下一頁」「跳到第 5 頁」「開始放映」），或按 Page Down／Page Up。 |
| Word | 直接讀取桌面、文件、下載、OneDrive 裡的 .docx，解題後另存在原檔同一個資料夾（檔名加「_小安解題」），不覆蓋原檔。 |
| Spotify | 開啟 Spotify App 並搜尋；沒裝 App 時改開網頁版。 |
| 本機檔案 | 用預設程式開啟 PowerPoint、Word、PDF、GeoGebra 等檔案。 |
| R | 安裝 R 後，統計結果可以直接在這台電腦執行 R，圖表顯示在小安裡。 |

其他功能（派題、黑板、繪圖、投影、對話）和網頁版完全相同。

## 安裝（第一次）

1. 安裝 Python 3：到 https://www.python.org/downloads/ 下載。安裝時勾選 **Add python.exe to PATH**。
2. （選用）安裝 Microsoft PowerPoint，才能控制簡報。
3. （選用）安裝 R：https://cran.r-project.org 。
4. 下載這個專案（GitHub 上按 **Code → Download ZIP**，解壓縮）。

不需要安裝其他套件。

## 每次使用

雙擊 `windows\啟動小安.bat`。會開一個黑色視窗，瀏覽器會自動開啟小安，畫面左上角會出現「Windows 本機版」。

要結束時，關閉那個黑色視窗。

## 安全

- 小安只在這台電腦上運作（127.0.0.1），其他電腦和其他網站都連不到。
- 只能讀寫桌面、文件、下載與 OneDrive 資料夾。若要加入其他資料夾，在啟動前設定環境變數 `XA_ROOTS`（多個資料夾用分號隔開）。
- 開啟簡報、開檔、播放音樂、存檔之前都會先問你。
- 存檔一律另存新檔，絕不覆蓋原檔。

## 學生用手機作答

本機版的網址（127.0.0.1）學生手機連不到。請把網頁版放到網路上（例如 GitHub Pages），到小安的「設定與記憶」：

1. 開啟「跨裝置作答」。
2. 在「學生作答頁網址」填入網頁版的網址。

QR Code 就會指向學生連得到的網址。

## 常見問題

- **黑色視窗說找不到 Python**：重新安裝 Python，記得勾選 Add python.exe to PATH。
- **「PowerPoint 沒有開啟」**：先按「開啟簡報」，或自己在 PowerPoint 開好簡報。
- **「簡報沒有在放映」**：先按「開始放映」或說「開始放映」。
- **連接埠被占用**：小安會自動換一個；或在啟動前設定 `XA_PORT`。
